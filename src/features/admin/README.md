# admin

Dashboard administrativo: métricas de alunos, financeiro, educação, plataforma (ver `docs/product-plan.md` seção 31).

CRUD de conteúdo educacional acontece no `/admin` do Payload CMS, não aqui. Este diretório cobre telas específicas do DespolarizaMED que o Payload não fornece (métricas de negócio, gestão de assinaturas/cupons, RBAC de usuários Better Auth).
